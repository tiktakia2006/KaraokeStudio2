# KaraokeStudio

Android-застосунок для караоке на Kotlin і Jetpack Compose та власний сервер на Node.js. Курсова робота з розробки програмного забезпечення мобільних пристроїв, тема 18. Автори: Провальський Тарас, Троцюк Андрій, група ТВ-31.

## Що вміє

- каталог пісень з текстами, які підсвічуються за часом (формат LRC);
- спів із відтворенням, записом голосу й оцінкою, історія, статистика, обране;
- власні пісні з телефону;
- обліковий запис, синхронізація між пристроями, рейтинг гравців;
- пошук тексту й обкладинок в інтернеті (LRCLIB та iTunes).

Без мережі й без облікового запису застосунок працює повністю.

Сервер:

```
cd server
npm start
```

Тести:

```
./gradlew testDebugUnitTest
./gradlew connectedDebugAndroidTest
cd server && npm test
```

## Структура

```
app/        Android-застосунок
server/     REST API
deploy/     розгортання сервера
docs/       документація, діаграми
tools/      скрипти перевірки
```
