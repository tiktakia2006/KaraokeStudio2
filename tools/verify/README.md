# Скрипти перевірки

Python 3. Не замінюють збірку Gradle й тести Android, а перевіряють те, що можна перевірити без Android SDK. Запуск з кореня проєкту: `python3 tools/verify/<скрипт>.py`.

| Скрипт | Що перевіряє |
|---|---|
| `check_kotlin.py` | XML, баланс дужок у Kotlin, відповідність `package` каталогам, імпорти між файлами |
| `check_imports.py` | символи бібліотек, використані без імпорту, делегати Compose |
| `check_calls.py` | виклики функцій і конструкторів проєкту: імена параметрів, кількість і обов'язкові аргументи |
| `check_consistency.py` | діаграми класів, ER, маршрути, фабрика ViewModel, демо-дані, збіг каталогу сервера з пресетами аудіо |
| `logic_port_tests.py` | Python-порти `LrcParser`, `ScoreCalculator`, пошуку, налаштувань і `DemoAudioGenerator` на реальних даних (потрібен `numpy`) |

Порти написані вручну за Kotlin-кодом: після зміни алгоритму в Kotlin їх треба оновити.
